Before you start

  
Reelfinder is only a window to a Telegram bot you choose. It does not host movies.

  
Use only bots and links that you are allowed to use.

  
It reads your bot's answers from Telegram Web. Telegram may not allow this. Use a spare account if you can.

  





  
Connect Telegram

  
Reelfinder opens Telegram Web in a hidden window. You log in once there (scan the QR code or use your phone number). No API keys are needed.

  
  

  
  
When you are logged in, press the Done button at the bottom of the Telegram page.
